关于本站

关于

把 Claude Code 官方英文 changelog 变成可检索、可对照的中文更新日志。

为什么做这个

Claude Code 几乎每个工作日都在发版，官方 changelog 是英文，而且很长。官方中文文档站覆盖了大部分文档，但 changelog 仍然跳转到英文原文。现有的社区项目要么只做摘要，要么只有裸 Markdown 全文，没有同时提供「摘要入口 + 逐条全文 + 中英对照 + 搜索」。

本站的定位是：摘要优先，全文兜底。首页用一分钟看完当天更新；需要排查时，进入版本页查每一条的英文原文和中文译文。

站内吉祥物使用 Claude Code 的 Clawd。Clawd 形象版权归 Anthropic 所有；本站为非官方、非商业使用，与 Anthropic 无隶属或背书关系。

数据来源

  • 主源：code.claude.com/docs/en/changelog
  • 兜底：anthropics/claude-code CHANGELOG.md，日期用 npm registry 补齐。

翻译方法

  • 按条目级 hash 缓存，只翻译新增或变更的条目。
  • 先翻译，再做一遍精修：纠正误译、去翻译腔、统一术语、保护代码片段。
  • 术语表约束译法；Claude Code 专有名词保留英文。
  • 校验条目数、行内代码 token 和长度比；不通过的条目标记「待校对」并保留英文。

更新频率

GitHub Actions 每小时检查一次。没有新版本就跳过，不产生翻译费用。当前已收录 {{ stats.versions | num }} 个版本、{{ stats['items'] | num }} 条更新，最新版本 {{ stats.latest }}（{{ stats.latest_date or '日期未知' }}）。

非官方声明

本站是非官方社区项目，不隶属 Anthropic，也未获其背书。英文原文版权归 Anthropic PBC 所有；翻译仅供学习参考，英文原文为准。机器翻译可能存在错误，欢迎通过 issue 或 PR 纠错。收到权利方的下架要求时，会及时移除相关内容。

参与贡献

  • 修正译文：编辑 data/overrides/zh-CN.json，按条目 hash 覆盖。
  • 修正术语：编辑 glossary.yml，递增 version。
  • 报告解析问题：附上版本号和原文片段。
  • 代码使用 MIT 许可证；翻译内容不单独主张版权。

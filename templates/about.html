关于本站

关于

将 Claude Code 官方英文 changelog 整理为可检索、可对照的中文更新日志。

项目背景

Claude Code 几乎每个工作日都会发布新版本，官方 changelog 只有英文，而且篇幅很长。官方中文文档站覆盖了大部分文档，但 changelog 仍然跳转到英文原文。现有社区项目大多只做摘要，或只提供原始 Markdown 全文，尚未同时提供「摘要入口 + 逐条全文 + 中英对照 + 搜索」。

本站的定位是：摘要优先，全文兜底。首页用一分钟了解当天更新；需要排查时，进入版本页查阅每一条的英文原文和中文译文。

站内吉祥物使用 Claude Code 的 Clawd。Clawd 形象版权归 Anthropic 所有；本站为非官方、非商业使用，与 Anthropic 无隶属或背书关系。

数据来源

  • 主源：code.claude.com/docs/en/changelog
  • 备用数据源：anthropics/claude-code CHANGELOG.md，发布日期从 npm registry 补齐。

翻译方法

  • 按条目 hash 缓存，只翻译新增或变更的条目。
  • 先翻译，再执行一次精修：纠正误译、消除翻译腔、统一术语，并保护代码片段不被改动。
  • 术语表约束译法；Claude Code 专有名词保留英文。
  • 校验条目数、行内代码 token 和长度比例；未通过的条目标记为「待校对」，并保留英文原文。

更新频率

GitHub Actions 每小时检查一次。没有新版本时会跳过翻译，只重新构建站点。当前已收录 {{ stats.versions | num }} 个版本、{{ stats['items'] | num }} 条更新，最新版本 {{ stats.latest }}（{{ stats.latest_date or '日期未知' }}）。
